# 机器层只执行和记录事实

机器层负责执行工具、保存状态、记录事件、暴露结果。

模型负责基于当前目标和证据判断下一步。

Runtime、tool registry、control plane、observability、checkpoint、verification 这些结构不能变成第二个脑子。

生命周期结构只负责把事实按阶段保存和暴露。它可以记录 turn、tool batch、provider recovery、session memory update 的开始、完成和失败，不能替模型判断任务路线。
