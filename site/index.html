Example

给它一个具体任务

比如你说：“帮我修一个上传失败的问题，顺便确认测试能过。”Kitty Agent 会把这个任务拆成一轮可检查的工程工作。

01

先定位

它会找上传入口、相关配置、报错位置和最近改动。

02

再修改

它会围绕真正相关的文件做最小修改。

03

跑检查

它会运行构建、测试或诊断，把结果摆出来。

04

留现场

它会记录读过什么、改过哪里、验证结果如何。

Who it is for

适合需要持续推进任务的人

Kitty Agent 适合维护项目、探索需求、修复问题和研究 agent 工作流。它把任务过程沉淀成下次能继续使用的事实。

维护项目

摸清现状，定位关键文件，围绕事实动手修。

做长任务

多轮、多文件、多次验证，都能保留现场。

探索新需求

一边确认事实，一边推进实现和验证。

研究 agent

直接观察上下文、工具、session 和验证如何协作。
