一个高级工程师的工作方式

Kitty Agent 不靠猜测写代码。先调查项目事实，再动手修改，最后自动验证并记录现场。每一步都像资深工程师一样严谨。

一键全局安装
安装后运行 kitty init 初始化项目，运行 kitty doctor 检查配置。
npm install -g @jun133/kitty
