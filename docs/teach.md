# Kitty Agent：从 0 到 1

## 01 工具循环

最开始，模型只有一个简单循环：用户问，模型想，模型答。

### 只有大脑的循环

```text
用户问题
  ↓
模型判断
  ↓
输出回答
```

模型本身像孙膑：孙膑是行动受限的军师，空有强大的大脑，自己无法行动。模型也是这样，它能分析、推理、安排下一步，但它自己碰不到外部项目。工具就是给它接上的外部能力，可以理解成望远镜、义肢、轮椅，或者任何让它能向外部探索的东西。

加入第一个工具后，模型开始能向外部探索。它先判断需不需要工具；需要时发出工具调用；系统执行工具得到工具结果；然后把“原来的用户问题 + 当前提示词 + 工具结果”一起喂回模型。模型再判断一次，继续调用工具，或者输出最终回答。

### 装入工具后的循环

```text
用户问题 + 当前提示词
  ↓
模型判断
  ↓
需要工具？
  ├─ 是：发出工具调用
  │       ↓
  │     系统执行工具
  │       ↓
  │     得到工具结果
  │       ↓
  │     用户问题 + 当前提示词 + 工具结果
  │       ↓
  │     回到“模型判断”
  │
  └─ 否：输出最终回答
```

## 02 短期记忆

### 具体例子

用户输入：

```text
帮我看看这个项目是干什么的。
```

模型可以先调用几个工具：

```text
工具调用：read("README.md")
工具调用：read("spec.md")
工具调用：bash("npm test")
```

工具结果回来后，模型知道：

```text
README：项目叫 Kitty，是一个智能体。
spec：核心链路是输入、上下文、模型、工具、状态、输出。
npm test：测试通过。
```

这一轮结束后，session 记住这些事：

```text
用户问题：帮我看看这个项目是干什么的。
模型调用过：read README.md、read spec.md、bash npm test。
工具结果：README 说明项目用途，spec 说明核心链路，测试通过。
活跃文件：README.md、spec.md。
最后回答：这个项目是一个智能体。
```

session 就是当前对话的工作现场。它把工具结果、活跃文件和最后回答留下来，下一轮可以接着这个现场继续。

## 03 长期记忆

长期记忆是项目长期放着的规则和经验。它让模型每次进入项目时，都能先知道这里长期遵守什么、有哪些已经沉淀好的做法。

在 Kitty 里，长期记忆主要来自两类东西：

```text
AGENTS.md
  项目的长期工作规则。

skills
  项目的长期能力包。
```

`AGENTS.md` 像项目规则：

```text
先看事实，再做判断。
先思考，再行动。
抓根本逻辑。
```

skill 像一份经过试错的熟练做法。上下文先给模型可用 skill 的名字和简介；模型判断任务需要某一份经验时，调用 `skill_load` 加载完整做法。

### 做菜例子

假设有一个 skill 叫“西红柿炒鸡蛋”：

```text
skill 名称：西红柿炒鸡蛋
skill 简介：适合把鸡蛋炒嫩、把西红柿炒出汁。
skill 细则：
  先把鸡蛋炒到刚凝固，盛出来。
  再把西红柿炒出汁。
  最后把鸡蛋倒回锅里一起收味。
```

用户输入：

```text
帮我做一盘西红柿炒鸡蛋。
```

模型看到这份 skill 可用，判断需要这套做法，于是调用 `skill_load("西红柿炒鸡蛋")`。
系统把 skill 细则放进当前上下文，模型按熟练做法继续回答。

## 04 上下文装配

上下文是这一轮真正喂给模型的整包输入。它会把前面几种东西装到一起：

```text
系统提示词
  + 人格提示词
  + 短期记忆
  + 长期记忆
  + 工具定义
  + 用户输入
  ↓
发给模型
```

### 具体例子

用户输入：

```text
这个项目已经写完了，请把 README 重写一下。
```

先把这一轮的积木摆出来：

```text
【系统提示词】你是本 session 的主导 agent。
【人格提示词】你是一位重视结构和事实的工程师，表达短、准、清楚。
【短期记忆】来自上一轮：项目的主要功能已经完成，README 已经有一份旧内容。
【长期记忆】长期规则是先看事实，再做判断，再行动；可用 skill 是“文档修改 skill”。
【工具定义】你可以使用两个工具：read 用来读取文件，edit 用来修改文件。
【用户输入】这个项目已经写完了，请把 README 重写一下。
```

系统把这六块拼成一段完整输入，发给模型：

```text
你是本 session 的主导 agent。你是一位重视结构和事实的工程师，表达短、准、清楚。上一轮已经确认项目的主要功能完成，README 还是旧说明。项目要求先看事实，再做判断，再行动；当前有一份“文档修改 skill”可用。你可以使用两个工具：read 用来读取文件，edit 用来修改文件。现在用户说：这个项目已经写完了，请把 README 重写一下。
```

模型拿到这段话后，知道该先用 `read` 打开旧 README，了解真实内容；再用 `edit` 重写说明。

完成后，它会回答：

```text
我已经根据现有内容重写了 README。
```

## 05 对话太长需要压缩

对话达到上下文极限时，模型已经装不下全部历史。Kitty 会把较早的对话整理成摘要，再把这份摘要和最近几轮对话、当前用户输入一起装进下一轮输入。

### 具体例子

Kitty 和用户已经聊了很多轮。早期对话里完成了项目初始化、读过 README、确认项目使用 TypeScript；最近几轮正在修改一个功能的测试。现在对话已经达到上下文极限。

Kitty 先把早期对话整理成摘要，然后模型会看到：

```text
【早期对话摘要】项目已经初始化。README 已读过。项目使用 TypeScript。
【最近对话】正在修改一个功能的测试。
【用户输入】把这个功能的提示也改清楚。
```

这样模型既知道前面已经做到哪里，也能集中处理眼前这一步。

## 06 计划和 To Do

复杂任务先把完整步骤拆出来，再全部写进 To Do list。列表写好后，模型从第一步开始执行，每次只有一个步骤处于进行中。

### 具体例子

用户输入：

```text
做一盘西红柿炒鸡蛋。
```

模型把计划写成 To Do list：

```text
[>] 1. 把鸡蛋炒到刚凝固，盛出来。
[ ] 2. 把西红柿炒出汁。
[ ] 3. 把鸡蛋倒回锅里，一起收味。
```

`[>]` 表示正在做，`[ ]` 表示后面要做。Kitty 的 To Do 只允许一个步骤处于进行中。第一步完成后，它会变成 `[x]`，第二步才变成新的 `[>]`。

## 07 后台任务

耗时命令可以进入后台。当前 agent 不需要停在原地等待，可以继续读取资料、修改文件或接收用户的新要求。

后台任务仍属于当前 session。Kitty 明确记录它的进程、输出和终态；session 退出或终端异常关闭时，会回收属于这个 session 的完整进程树。

### 具体例子

测试需要运行一段时间时，可以启动后台任务：

```text
background_run("npm test")
```

agent 可以继续处理其他步骤，需要结果时再读取输出或等待终态。后台任务不会创建另一个 agent，也不会共享其他 session 的记录。

## 最后看一个完整例子

下面把前面讲的东西放回同一个西红柿炒鸡蛋任务里。这个任务已经进行了几轮。

**工具循环**

Kitty 先查资料，再加载做法：

```text
【工具调用】read("食材清单.md")
【工具结果】有 3 个西红柿、4 个鸡蛋，家里有人喜欢鸡蛋炒嫩一点。

【工具调用】skill_load("西红柿炒鸡蛋")
【工具结果】鸡蛋先炒到刚凝固，西红柿炒出汁后，再把鸡蛋倒回锅里。
```

**短期记忆**

这一轮留下了三件当前事实：食材够用、鸡蛋要炒嫩、已经加载了西红柿炒鸡蛋的做法。

**长期记忆**

项目长期规则告诉模型：先看事实，再做判断，再行动。西红柿炒鸡蛋 skill 提供已经试过的熟练做法。

**后台任务**

烹饪计时可以进入后台：

```text
background_run("计时 3 分钟")
```

计时任务仍属于当前 session，agent 可以在等待时继续整理做法。

现在用户继续说：

```text
鸡蛋再嫩一点，少放糖。
```

**上下文装配**

Kitty 把上面的事实拼成一段话，发给模型：

```text
你是当前 session 的 agent。你是一位重视结构和事实的工程师，表达短、准、清楚。现在要做西红柿炒鸡蛋，食材清单已经确认有 3 个西红柿、4 个鸡蛋，用户喜欢鸡蛋炒嫩一点。项目长期规则要求先看事实，再做判断，再行动。已经加载的西红柿炒鸡蛋 skill 说明：鸡蛋先炒到刚凝固，西红柿炒出汁后，再把鸡蛋倒回锅里。计时任务正在后台运行。你可以用 read 读取资料，用 skill_load 加载熟练做法。现在用户说：鸡蛋再嫩一点，少放糖。
```

**计划和 To Do**

这是一个需要按顺序完成的任务，Kitty 先拆成以下步骤：

```text
[>] 按更嫩的做法处理鸡蛋。
[ ] 炒西红柿。
[ ] 把鸡蛋倒回锅里收味。
```

前两步完成后，最后一步处于进行中：

```text
[x] 按更嫩的做法处理鸡蛋。
[x] 炒西红柿。
[>] 把鸡蛋倒回锅里收味。
```

最后一步完成，端上一盘西红柿炒鸡蛋。
